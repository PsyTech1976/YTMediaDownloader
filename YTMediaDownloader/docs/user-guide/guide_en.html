1. Introduction & Requirements

YTMediaDownloader Pro is a modern desktop utility designed to analyze, download, and multiplex YouTube video streams, multitrack audio channels, and subtitles safely and rapidly.

The package is fully self-contained: it bundles high-performance multimedia engines (yt-dlp, ffmpeg, ffprobe, and required libraries) without requiring separate external dependencies.

2. Quick Start, Automatic Focus & Single Instance

Upon launching the application:

  • Automatic Input Focus: The typing cursor is instantly positioned inside the YouTube Video Link field, allowing immediate pasting with Ctrl+V or the dedicated button.
  • Single Instance Enforcement: If the application is already running, starting another instance will display a warning and safely terminate to protect concurrent operations.

3. Menu Bar & Keyboard Shortcuts

The application features a comprehensive top menu bar providing convenient shortcuts:

  • File Menu:
    • Paste & Analyze Link (Ctrl+V)
    • Start Download (Ctrl+D)
    • Cancel Process (Esc)
    • Open Downloaded File (Ctrl+O)
    • Show in Folder (Ctrl+F)
    • Exit (Ctrl+Q)
  • Options Menu:
    • Edit Video/Audio Options... (Ctrl+E)
    • System Menu Integration (toggle visibility in OS search)
    • Settings... (Ctrl+,)
  • Language Menu: Enables instant language switching with national flag indicators (🇮🇹 Italiano, 🇬🇧 English, 🇫🇷 Français, 🇩🇪 Deutsch, 🇪🇸 Español).
  • Help Menu:
    • User Guide (F1)
    • About Software... (Ctrl+I)

4. OS Desktop Search & Menu Integration

Use the Integrate with System / In System Menu button in the top bar:

  • Enable (➕ Integrate with System): Creates an XDG-compliant .desktop entry and high-res icon in your user applications folder. The app immediately becomes searchable in your OS application launcher (GNOME Shell, KDE KRunner, Whisker Menu, etc.).
  • Disable (✔ In System Menu): Removes the desktop launcher from the OS menu system while keeping your portable AppImage file intact.

5. Video Link Analysis

Click Paste & Analyze Link to automatically read the URL from the system clipboard and initiate stream discovery across all available resolutions and formats.

6. Format, Audio & Subtitle Selection

The media analyzer dialog lets you customize resolution (up to 4K/8K 60fps), container format (MP4, MKV, WebM), audio streams (original, localized, and other languages), and manual/automatic subtitles.

7. Downloading & Process Monitoring

During downloads, FFmpeg background processing is executed on a dedicated worker thread, keeping the GUI responsive while displaying percentage, active phase, and estimated time remaining.

8. FFmpeg Finalization & Language Tags

Streams are multiplexed with ISO 639-2 language tags and descriptive track titles, ensuring video players (such as VLC, smart TVs, and mobile players) clearly display tags like Track 1 - [English].

9. Opening & Locating Files on Desktop

The Show in Folder button is always enabled:

  • If a video has been downloaded, it highlights and selects the file in your desktop file manager.
  • If no download has completed yet, it opens the target folder showing its directory contents.
